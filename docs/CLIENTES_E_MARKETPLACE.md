## Padrões Observados: ML vs Amazon

| Dimensão | Mercado Livre | Amazon |
|----------|---------------|--------|
| **Título** | Curto, keyword-rich, marca no início | Longo, atributos completos, SEO-heavy |
| **Preço** | Mais variável (promoções agressivas) | Mais estável, Prime influencia |
| **Imagens** | 1-3 fotos, fundo branco opcional | Mínimo 5, fundo branco obrigatório, A+ content |
| **Reviews** | Menos críticos para ranking | Críticos — precisa 15+ reviews para tração |
| **Logística** | Mercado Envios Full = boost ranking | FBA = boost + Prime badge |
| **Recebimento** | D+15 | D+60 |
| **Comissão** | 11-16% | 8-15% (varia categoria) |
| **Público** | Preço-sensível, promoções | Qualidade + entrega rápida |

**Implicação F5**: Publicar primeiro no ML (validação rápida, cash flow D+15), depois Amazon (escala + credibilidade).
